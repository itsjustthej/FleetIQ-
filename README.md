# FleetIQ — AI-Powered Fleet Management Website

FleetIQ is a modern responsive business website concept for an AI-powered fleet and logistics management platform.

## Sections
- Hero / Home
- Smart Routing, Fleet Visibility & Predictive Insights
- Interactive-style Fleet Control Center dashboard
- Features
- Business impact metrics
- Contact / Demo form
- Responsive footer

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- No external libraries or dependencies

## Run locally
Open `index.html` in any modern browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, .
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated Pages URL.

> This is an educational/demo website created to demonstrate AI-assisted website generation. Dashboard figures are illustrative.
